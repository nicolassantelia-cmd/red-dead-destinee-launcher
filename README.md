# Red Dead Destinée — Launcher officiel

Dépôt public utilisé pour distribuer les mises à jour du launcher officiel de Red Dead Destinée.

## Mise à jour automatique

Le launcher consulte un manifeste public afin de détecter les nouvelles versions.

Les installateurs sont distribués dans les GitHub Releases de ce dépôt.
